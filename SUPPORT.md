# Support

6D Mail Pro is an unreleased development scaffold. Runtime integration is not yet verified.

Verified author contact: [Maalig@pmpksamy.com](mailto:Maalig@pmpksamy.com), [IAMPMPKSAMY](https://pmpksamy.com/).

Report reproducible issues at [https://github.com/iampmpksamy/NextCloud_6D_Mail_Pro/issues](https://github.com/iampmpksamy/NextCloud_6D_Mail_Pro/issues). Include synthetic reproduction steps and the tested version. Documentation is maintained in this repository.

For a report include app/Nextcloud/Mail/PHP versions, browser, affected route, whether Mail alone works, and steps using synthetic data. Do not attach complete config.php, cookies, passwords, tokens, real messages, account addresses or raw production logs. Future troubleshooting should ask for minimal redacted error details.
